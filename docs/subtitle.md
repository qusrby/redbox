# 녹화에 자막과 그림 얹기

다른 프로그램이 내놓는 글(해설, 메모, 진행 상황, 번역 등)이나 그림(말상자, 강조 표시, 진행 표시 등)을 녹화 영상 위에 함께 녹화하는 기능입니다. Redbox 는 게임 창만 캡처하므로 다른 프로그램이 화면에 띄운 창은 녹화에 들어가지 않습니다. 그래서 글과 그림을 파일로 받아 Redbox 가 녹화하는 장면에 직접 얹습니다.

Redbox 는 글이나 그림을 만들지 않습니다. 정해진 파일을 읽어 얹기만 합니다.

## 켜기

설정 > 녹화 > 자막 파일(글), 그림 파일(PNG)에서 파일을 고릅니다. 아직 없는 파일도 이름을 적어 정할 수 있습니다. 끄기를 누르면 꺼집니다(기본값은 둘 다 꺼짐). 둘 다 정하면 그림 위에 글 자막을 얹습니다.

자막과 그림은 영상에 그대로 녹화되어 유튜브에도 그대로 올라갑니다. 나중에 빼거나 고칠 수 없습니다.

## 자막 파일 약속 (글을 내놓는 쪽)

- UTF-8 글 파일 하나. 파일이 비어 있거나 없으면 아무것도 보이지 않습니다.
- 임시 파일에 쓴 뒤 바꿔치기해서, 반쯤 쓰인 파일이 보이지 않게 합니다.
- 갱신 간격은 자유입니다. Redbox 는 0.5초마다 파일을 보고 바뀌면 따라 바꿉니다.
- JSON 이면 아래 항목을 읽고, JSON 이 아니면 내용 전체를 자막으로 보고 기본 모양(화면 아래)으로 보여 줍니다.

```json
{
  "text": "보스 2페이즈 진입\n남은 회복약 3개",
  "anchor": "bottom",
  "width": 0.7,
  "size": 0.04,
  "opacity": 0.6
}
```

| 항목 | 뜻 | 기본값 |
| --- | --- | --- |
| `text` | 보여 줄 글. 줄바꿈은 그대로 | (없으면 안 보임) |
| `anchor` | 자리: `bottom`, `top`, `left`, `right`, `top-left`, `top-right`, `bottom-left`, `bottom-right` | `bottom` |
| `width` | 자막 칸의 최대 폭, 화면 폭 대비(0.1~1) | `0.7` |
| `size` | 글자 크기, 화면 높이 대비(0.01~0.2) | `0.04` |
| `opacity` | 검은 바탕의 불투명도(0~1) | `0.6` |

- 긴 줄은 폭에 맞춰 줄바꿈하고, 화면보다 긴 글은 마지막 줄들만 보여 줍니다.
- 깨진 JSON 을 읽으면 직전 자막을 그대로 두고 다음 갱신을 기다립니다.
- 글꼴은 윈도우 글꼴 폴더에 Pretendard 가 설치되어 있으면 Pretendard, 없으면 맑은 고딕입니다(OBS 는 사용자 한 명에게만 설치된 글꼴을 쓰지 못합니다).

## 그림 파일 약속 (그림을 내놓는 쪽)

- 투명 배경(알파 채널) PNG 한 장. 그림 전체가 게임 화면 전체에 대응하므로, 비율은 게임 화면과 같게 내놓습니다(크기는 달라도 됨).
- 보여 줄 것이 없으면 완전히 투명한 그림을 내놓거나 파일을 지웁니다. 파일이 없으면 아무것도 보이지 않습니다.
- 임시 파일에 쓴 뒤 바꿔치기합니다. 갱신 간격은 자유입니다(움직이는 그림은 다루지 않음). Redbox 가 0.5초마다 파일을 보고 바뀌면 OBS 가 바로 다시 읽게 합니다.
- 그림은 게임 캡처와 같은 자리, 같은 크기로 겹칩니다. 창 모드나 비율이 다른 게임이라 게임 화면이 장면을 다 채우지 않아도, 그림 속 자리가 게임 화면의 자리와 맞습니다.

## 동작

- 녹화를 시작할 때 녹화되는 OBS 장면 맨 위에 소스를 얹고(그림 `Redbox Overlay Image`, 그 위에 자막 바탕 `Redbox Subtitle Box`와 글 `Redbox Subtitle`), 녹화가 끝나면 치웁니다.
- 앱이나 PC 가 꺼져 치우지 못한 소스는 다음에 OBS 에 연결할 때 치웁니다.
- 자막이나 그림을 얹거나 고치다 오류가 나도 녹화는 그대로 계속됩니다.
