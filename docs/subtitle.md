# 녹화에 자막 얹기

다른 프로그램이 내놓는 글(해설, 메모, 진행 상황, 번역 등)이나 그림(말상자, 강조 표시, 진행 표시 등)을 녹화 영상 위에 함께 녹화하는 기능입니다. Redbox 는 게임 창만 캡처하므로 다른 프로그램이 화면에 띄운 창은 녹화에 들어가지 않습니다. 그래서 얹을 것을 파일로 받아 Redbox 가 녹화하는 장면에 직접 얹습니다.

Redbox 는 무엇을 보여 줄지 정하지 않습니다. 통합 자막 파일이 적은 대로 얹고 치우기만 합니다.

## 켜기

설정 > 녹화 > 자막 파일에서 통합 자막 파일(JSON)을 고릅니다. 아직 없는 파일도 이름을 적어 정할 수 있습니다. 끄기를 누르면 꺼집니다(기본값은 꺼짐).

자막은 영상에 그대로 녹화되어 유튜브에도 그대로 올라갑니다. 나중에 빼거나 고칠 수 없습니다.

## 통합 자막 파일 (내놓는 쪽이 지키는 약속)

UTF-8 JSON 파일 하나입니다. 얹을 것을 `layers` 목록에 적고, 앞에 적은 것이 아래에 깔립니다. 개수 제한은 없습니다.

```json
{
  "layers": [
    {"image": "지금 생각.png"},
    {"text_file": "메모.txt", "anchor": "bottom-left", "size": 0.03},
    {"text": "1장: 계약의 갑작스러운 해지", "anchor": "top"}
  ]
}
```

| 칸 | 뜻 |
| --- | --- |
| `image` | 투명 PNG 를 게임 화면 전체에 겹칩니다 |
| `text_file` | 글 파일의 내용을 글 칸으로 보여 줍니다 |
| `text` | 적은 글을 그대로 글 칸으로 보여 줍니다 |

- 파일 경로는 통합 자막 파일이 있는 폴더 기준입니다(절대 경로도 됨).
- 통합 자막 파일이 없거나, 비었거나, `layers` 가 비면 아무것도 보이지 않습니다.
- 깨진 JSON 을 읽으면 직전 상태를 그대로 두고 다음 갱신을 기다립니다.
- Redbox 는 0.5초마다 통합 자막 파일과 그 파일이 가리키는 파일들을 보고, 바뀌면 따라 바꿉니다. 목록이 바뀌면 얹은 것을 다시 만듭니다.
- 모든 파일은 임시 파일에 쓴 뒤 바꿔치기해서, 반쯤 쓰인 파일이 보이지 않게 합니다.

### 그림 칸

- 투명 배경(알파 채널) PNG. 그림 전체가 게임 화면 전체에 대응하므로, 비율은 게임 화면과 같게 내놓습니다(크기는 달라도 됨).
- 그림은 게임 캡처와 같은 자리, 같은 크기로 겹칩니다. 창 모드나 비율이 다른 게임이라 게임 화면이 장면을 다 채우지 않아도, 그림 속 자리가 게임 화면의 자리와 맞습니다.
- 보여 줄 것이 없으면 완전히 투명한 그림을 내놓거나 파일을 지웁니다. 움직이는 그림은 다루지 않습니다.

### 글 칸

반투명 검은 바탕에 흰 글입니다. 글 파일은 UTF-8, 줄바꿈은 그대로 보여 주고, 비어 있거나 없으면 그 칸은 보이지 않습니다.

| 항목 | 뜻 | 기본값 |
| --- | --- | --- |
| `anchor` | 자리: `bottom`, `top`, `left`, `right`, `top-left`, `top-right`, `bottom-left`, `bottom-right` | `bottom` |
| `width` | 글 칸의 최대 폭, 화면 폭 대비(0.1~1) | `0.7` |
| `size` | 글자 크기, 화면 높이 대비(0.01~0.2) | `0.04` |
| `opacity` | 검은 바탕의 불투명도(0~1) | `0.6` |

- 긴 줄은 폭에 맞춰 줄바꿈하고, 화면보다 긴 글은 마지막 줄들만 보여 줍니다.
- 글꼴은 윈도우 글꼴 폴더에 Pretendard 가 설치되어 있으면 Pretendard, 없으면 맑은 고딕입니다(OBS 는 사용자 한 명에게만 설치된 글꼴을 쓰지 못합니다).

## 동작

- 녹화를 시작할 때 녹화되는 OBS 장면 맨 위에 칸마다 소스(`Redbox Layer 1 Image`, `Redbox Layer 2 Text` 등)를 얹고, 녹화가 끝나면 치웁니다.
- 앱이나 PC 가 꺼져 치우지 못한 소스는 다음에 OBS 에 연결할 때 치웁니다.
- 자막을 얹거나 고치다 오류가 나도 녹화는 그대로 계속됩니다.
