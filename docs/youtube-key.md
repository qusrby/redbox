# 유튜브 키 만들기

Redbox 는 녹화한 영상을 **사용자 본인의 구글 클라우드 프로젝트**로 유튜브에 올립니다. 키는 한 번만 만들면 되고, 10분쯤 걸립니다. 키와 로그인 정보는 내 PC 의 `%APPDATA%\Redbox\youtube` 폴더에만 저장됩니다.

## 1. 구글 클라우드 프로젝트 만들기

1. [새 프로젝트](https://console.cloud.google.com/projectcreate) 페이지를 엽니다.
2. 프로젝트 이름을 정하고(예: `Redbox`) **만들기**를 누릅니다.
3. 화면 위 프로젝트 선택 칸에 방금 만든 프로젝트가 선택되어 있는지 확인합니다. 아래 단계는 모두 이 프로젝트 안에서 합니다.

## 2. YouTube Data API v3 사용

1. [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) 페이지를 엽니다.
2. **사용**을 누릅니다.

## 3. 동의 화면 만들고 앱 게시

로그인할 때 구글이 보여 주는 화면입니다.

1. [Google 인증 플랫폼](https://console.cloud.google.com/auth/overview) 페이지에서 **시작하기**를 누릅니다.
2. 앱 이름(예: `Redbox`)과 지원 이메일을 넣습니다.
3. 대상은 **외부**를 고릅니다.
4. 연락처 이메일을 넣고 정책에 동의한 뒤 **만들기**를 누릅니다.
5. 왼쪽 메뉴 **대상**에서 **앱 게시**를 누르고 확인합니다. 게시 상태가 **프로덕션**이 되어야 합니다.

> 게시하지 않고 '테스트' 상태로 두면 로그인이 7일마다 풀립니다. 구글 검증은 받지 않아도 됩니다. 나만 쓰는 프로젝트라 검증 없이도 업로드할 수 있고, 올린 영상도 정상입니다.

## 4. 클라이언트 만들고 JSON 내려받기

1. [클라이언트 만들기](https://console.cloud.google.com/auth/clients/create) 페이지를 엽니다.
2. 애플리케이션 유형은 **데스크톱 앱**을 고르고, 이름은 아무거나 넣은 뒤 **만들기**를 누릅니다.
3. 만들어진 창에서 **JSON 다운로드**를 눌러 파일을 받습니다. 이 파일이 키 파일입니다.

> 클라이언트 보안 비밀번호는 만든 직후 이 창에서만 보여 줍니다. 창을 닫기 전에 꼭 내려받으십시오. 놓쳤다면 클라이언트에 새 보안 비밀번호를 추가하거나 클라이언트를 새로 만들면 됩니다.

> 키 파일은 다른 사람에게 주거나 인터넷에 올리지 마십시오.

## 5. Redbox 에서 로그인

1. 첫 실행 안내의 유튜브 단계나 **설정 > 유튜브 업로드**에서 **키 파일 선택 및 로그인**을 누릅니다.
2. 4단계에서 받은 JSON 파일을 고릅니다.
3. 브라우저가 열리면 영상을 올릴 구글 계정을 고릅니다. 브랜드 계정 채널에 올리려면 그 채널을 고릅니다.
4. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급**을 누르고 **(앱 이름)(으)로 이동**을 누릅니다. 내가 만든 프로젝트라서 나오는 경고입니다.
5. 유튜브 권한을 허용하면 Redbox 에 **로그인 완료**와 채널 이름이 나옵니다.

## 한도

- 업로드는 구글 프로젝트마다 하루 100개까지입니다. Redbox 의 하루 업로드 상한(기본 20개)은 설정에서 바꿀 수 있습니다.
- 영상은 기본으로 **비공개**로 올라갑니다.
